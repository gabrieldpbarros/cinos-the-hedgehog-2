# Créditos das fontes

A interface usa duas famílias de fontes abertas, ambas sob a **SIL Open Font License 1.1 (OFL)**. Os arquivos `.woff2` usados pelo jogo e os textos integrais das licenças estão em `public/fonts/`.

## Bungee

- **Uso no projeto:** títulos, marca, números do HUD e resultados.
- **Criador/projeto:** The Bungee Project Authors, de David Jonathan Ross.
- **Origem:** [Google Fonts — Bungee](https://fonts.google.com/specimen/Bungee) e [repositório oficial](https://github.com/djrrb/Bungee).
- **Licença:** SIL Open Font License 1.1.
- **Arquivo:** `public/fonts/bungee-latin.woff2`.
- **Licença local:** `public/fonts/OFL-Bungee.txt`.
- **Crédito exigido:** Copyright 2023 The Bungee Project Authors (https://github.com/djrrb/Bungee).

## Chakra Petch

- **Uso no projeto:** textos do HUD, controles, botões, descrições e créditos.
- **Criador/projeto:** The Chakra Petch Project Authors, de Cadson Demak.
- **Origem:** [Google Fonts — Chakra Petch](https://fonts.google.com/specimen/Chakra+Petch) e [repositório oficial](https://github.com/m4rc1e/Chakra-Petch).
- **Licença:** SIL Open Font License 1.1.
- **Arquivos:** `public/fonts/chakra-petch-400-latin.woff2`, `chakra-petch-600-latin.woff2` e `chakra-petch-700-latin.woff2`.
- **Licença local:** `public/fonts/OFL-ChakraPetch.txt`.
- **Crédito exigido:** Copyright 2018 The Chakra Petch Project Authors (https://github.com/m4rc1e/Chakra-Petch.git).

## Onde o crédito aparece

- No rodapé do jogo, em `index.html`, com links para as páginas das fontes.
- Neste documento e no `README.md`.

As fontes foram baixadas como subconjuntos latinos em `.woff2` fornecidos pelo Google Fonts e não tiveram seus desenhos alterados. A OFL permite uso, cópia, modificação e distribuição, desde que o aviso de copyright e a licença sejam mantidos; os textos completos estão nos arquivos `OFL-*.txt` citados acima.
